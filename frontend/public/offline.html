Start it by hand instead

Open the folder where the tool is installed and double-click Start RTDS Data Collection Audit.command on macOS, or Start RTDS Data Collection Audit.bat on Windows. This page reloads on its own once it is up.

To skip this step for good, run Install background start from that same folder: the tool then starts with your session and is always ready.
